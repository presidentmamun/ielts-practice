# IELTS Practice Desk

A free practice app for computer-delivered IELTS-style tests: timed Listening, Reading and Writing, band estimates, explanations for every answer, highlight and review tools. Works offline once installed ("Add to Home Screen").

All questions, passages and recordings are original. Listening audio is generated with the open-source Kokoro-82M model (Apache-2.0).
This is an independent tool and is not affiliated with or endorsed by IELTS, the British Council, IDP or Cambridge University Press & Assessment.
